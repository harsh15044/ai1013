## 📊 Project Breakdown

### Assignment 1: Statistical Analysis & Information Theory
**🔍 Neuroscience Data Analysis & Distribution Modeling**

- **Objective**: Analyze neural firing patterns and search behavior through statistical modeling
- **Key Implementations**:
  - Computation of relative entropy (KL divergence) between probability distributions
  - L1 distance calculations for distribution comparison
  - Gamma distribution parameter estimation and fitting
  - Laplace smoothing for handling zero-probability events
- **Technologies**: NumPy, Pandas, SciPy, Matplotlib, Seaborn
- **Skills**: Statistical modeling, probability theory, data preprocessing, visualization
- **Datasets**: Neural firing rates and search times data

### Assignment 2: Fundamental Machine Learning
**🧠 Neural Networks & Classification Systems**

#### Part 1: Artificial Neural Network (From Scratch)
- **Objective**: Build and train a neural network without using ML libraries
- **Implementation**: 
  - Forward propagation with configurable architecture
  - Backpropagation algorithm for gradient computation
  - Custom activation functions and loss optimization
- **Skills**: Deep understanding of neural network mathematics, gradient descent

#### Part 2: k-Nearest Neighbors Classification
- **Objective**: Implement KNN classifier for biological data classification
- **Dataset**: Abalone age prediction (UCI Machine Learning Repository)
- **Implementation**:
  - Data preprocessing and feature engineering
  - Distance metric optimization
  - Cross-validation and hyperparameter tuning
- **Skills**: Classification algorithms, data cleaning, model evaluation

### Assignment 3: Deep Learning with PyTorch
**⚡ Advanced Neural Networks**

- **Objective**: Leverage PyTorch for sophisticated deep learning implementations
- **Key Features**:
  - Custom dataset construction and data loading
  - Advanced neural network architectures with ReLU activations
  - GPU acceleration and tensor operations
- **Technologies**: PyTorch, CUDA (if available)
- **Skills**: Deep learning frameworks, tensor operations, modern ML practices

### Assignment 4: Unsupervised Learning
**🎯 Clustering & Pattern Recognition**

- **Objective**: Implement and analyze K-Means clustering algorithm
- **Implementation**:
  - Synthetic dataset generation for clustering validation
  - K-Means algorithm with K-means++ smart initialization
  - Cluster analysis and visualization
  - Performance metrics and convergence analysis
- **Technologies**: NumPy, Matplotlib, Seaborn
- **Skills**: Unsupervised learning, data generation, clustering evaluation

### Assignment 5: Advanced Probability & Optimization
**🎲 Sampling Theory & Game Strategy Optimization**

#### Part 1: Monte Carlo Methods
- **Objective**: Implement inverse transform sampling for custom probability distributions
- **Features**:
  - Custom probability density function implementation
  - Inverse CDF computation and sampling
  - Animated visualization of sampling convergence
- **Skills**: Probability theory, Monte Carlo methods, statistical sampling

#### Part 2: Wordle Game Strategy Optimization
- **Objective**: Develop optimal strategy for Wordle using probability and optimization
- **Implementation**:
  - Letter frequency analysis across all positions
  - Bayesian probability calculations for word guessing
  - Convex optimization using CVXPy for strategy optimization
  - Greedy algorithm implementation and performance analysis
- **Technologies**: CVXPy, NumPy, advanced probability theory
- **Skills**: Game theory, optimization, Bayesian analysis, strategy development
